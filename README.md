# Daniel Ghaly Portfolio

Premium single-page portfolio for Daniel Ghaly, built with Next.js App Router, TypeScript, Tailwind CSS, and Motion.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

If port `3000` is occupied:

```bash
npm run dev -- --port 3001
```

## Build

```bash
npm run build
```

## Deploy

Deploy to Vercel from the project root. The site uses static content from `src/content/` and local assets from `public/images/`.

## Content

- Navigation, socials, and contact: `src/content/site.ts`
- Work/project imagery: `src/content/work.ts`
- Services and principles: `src/content/services.ts`
- Process: `src/content/process.ts`
- Pricing: `src/content/pricing.ts`
- FAQ: `src/content/faq.ts`
